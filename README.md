## 📝 Project Overview
**AI Python Code Explainer** is an interactive web application built with **Streamlit** and powered by the **Google GenAI SDK** (`gemini-3.6-flash`). Designed as an accessible learning assistant for programmers and beginners, the application accepts arbitrary Python code snippets and generates clear, beginner-friendly explanations formatted to the user's preferred detail level.

---

## ✨ Features
* **Interactive Code Input:** Paste Python code snippets directly into a dedicated, multi-line text editor.
* **Tailored Explanation Modes:** Choose from four distinct breakdown formats depending on learning needs:
  * Beginner Explanation
  * Line-by-Line Explanation
  * Short Summary
  * Explain Code and Output
* **Interactive Tutor / AI Assistant:** Leverages structured prompts acting as a Python instructor to break down variables, functions, execution flow, and expected output.
* **Real-time Generation:** Renders instant, formatted Markdown explanations with interactive loading indicators.

---

## 🛠️ Tech Stack & Dependencies
* **Frontend / UI:** Streamlit
* **Generative AI Platform:** Google GenAI SDK (`google-genai`), utilizing the `gemini-3.6-flash` model
* **Environment Management:** `python-dotenv`
* **Language:** Python 3.x
